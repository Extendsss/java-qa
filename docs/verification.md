## 重复检查

```powershell
mvn -B verify
node scripts/check-frontend.cjs
```

运行中的本地测试服务可用以下脚本检查简历和模板业务。脚本会创建测试用户、简历与分块定义，完成后软删除本次简历和自定义模板，保留测试用户；应当对专用测试环境运行。

```powershell
.\scripts\smoke-resumes.ps1 -BaseUrl 'http://127.0.0.1:18080'
```
